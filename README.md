# 个人收藏夹导出 Chrome Extension

本插件是本地使用的 Manifest V3 扩展，用于在用户主动点击后导出本人已登录账号中的 B 站收藏夹，以及小红书当前页面已加载收藏内容。

## 本地加载

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录：`extension/`。
5. 打开 B 站或小红书收藏页面，点击浏览器工具栏中的插件图标使用。

## 使用说明

- B 站：先登录 B 站，点击「读取 B 站收藏夹」，选择一个或多个收藏夹，设置时间和失效内容选项后导出。
- 小红书：先打开收藏页，滚动加载需要导出的内容，再点击导出。首版只解析当前页面已加载内容。

## 数据说明

- 插件不提供后端服务，不上传收藏数据。
- 所有导出数据在本地浏览器中处理。
- Excel 包含 `收藏内容`、`失效内容`、`导出说明`、`错误日志` 四个 Sheet。
