# fav-export-extension

一键导出 B 站、小红书内容到 Excel 的 Chrome 插件，方便知识管理、备份和后续分析。

本插件是本地使用的 Manifest V3 扩展，用于在用户主动点击后导出当前浏览器可访问的数据。插件不下载视频文件本体，只导出视频链接、基础数据、字幕文本等结构化信息。

## 本地加载

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录：`extension/`。
5. 打开 B 站或小红书页面，点击浏览器工具栏中的插件图标使用。

## 使用说明

- B 站收藏夹：先登录 B 站，选择「读取收藏夹」，点击「读取 B 站收藏夹」，选择一个或多个收藏夹，设置时间和失效内容选项后导出。
- B 站 UP 主：选择「读取 UP 主」，输入 UID 或空间链接，读取投稿信息后可按排序、关键词、分区、投稿时间导出公开投稿。
- 小红书：先打开收藏页，滚动加载需要导出的内容，再点击导出。首版只解析当前页面已加载内容。

弹窗会缓存上一次的平台、模式、输入、时间范围和勾选项，误关闭后重新打开会自动恢复。

## 数据说明

- 插件不提供后端服务，不上传收藏数据。
- 所有导出数据在本地浏览器中处理。
- Excel 包含 `收藏内容`、`失效内容`、`导出说明`、`错误日志` 四个 Sheet。
- 视频基础数据会尽量拆分为独立列：播放、点赞、收藏、投币、分享、评论、弹幕、时长、字幕文本等。
- YouTube 入口暂时隐藏，相关能力后续明确方案后再开放。
